# سيرفر A: تحقق برقم الهاتف عبر SMS

## 1) حساب Twilio (مرة واحدة)
1. سجّل في twilio.com واحصل على Account SID وAuth Token.
2. من Verify ← Services أنشئ خدمة جديدة وانسخ Service SID.
3. الحساب التجريبي يرسل فقط للأرقام المضافة عندك كأرقام موثّقة. للإرسال لأي رقم في العالم رقّي الحساب.
   بعض الدول تشترط تسجيل المرسل، راجع صفحة الدول المدعومة في Twilio.

## 2) تجربة محلية
    npm install
    cp .env.example .env     # ثم املأ المفاتيح الثلاثة
    npm start                # افتح http://localhost:3000

## 3) نشر عالمي (مثال Render)
1. ارفع المجلد إلى GitHub.
2. في render.com: New ← Web Service ← اختر المستودع.
3. Build: `npm install` ، Start: `npm start`.
4. من Environment أضف TWILIO_ACCOUNT_SID وTWILIO_AUTH_TOKEN وTWILIO_VERIFY_SERVICE_SID.
5. افتح الرابط الذي يعطيك إياه Render، وهو التطبيق الشغّال.

## ملاحظات
- المفاتيح تبقى في السيرفر فقط ولا تضعها في الصفحة أبدًا.
- هذا يثبت ملكية الرقم فقط. لحسابات دائمة ورسائل بين المستخدمين تحتاج قاعدة بيانات وجلسات دخول (الخطوة التالية).
- الصفحة تحدّ المحاولات (5 إرسال و10 تحقق كل 10 دقائق لكل جهاز).
